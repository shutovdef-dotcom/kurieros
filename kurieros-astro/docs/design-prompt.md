# Промпт для код-дизайн агента: КурьерОк (`kurerok.ru`)

> Цель: **обновить визуал сайта** — палитра, типографика, отступы, состояния, ощущение «свежести». **Без переделывания структуры**: имена компонентов, разметка, классы, скрипты, поведение фильтров и модалок остаются такими же. Только косметика и токены.

---

## 1. Что это за сайт

КурьерОк — статический Astro-сайт, агрегатор вакансий курьеров и банковских представителей. Аудитория: трудовые мигранты СНГ, студенты, пенсионеры. Сейчас сайт работает корректно — нужно сделать его визуально приятнее, современнее и приветливее, не ломая того, что есть.

## 2. Технические рамки (нельзя нарушать)

- Astro 6.1.3, `output: 'static'`, чистый CSS.
- **Не добавлять** UI-фреймворки (React/Vue/Svelte), Tailwind, CSS-in-JS, Sass.
- **Не добавлять** новые рантайм-зависимости в `package.json` (за исключением, может быть, одного веб-шрифта через `@font-face` локально).
- **Не менять** имена компонентов, файлов, экспортов.
- **Не менять** разметку: `data-t="..."` атрибуты, классы, id, дата-атрибуты.
- **Не трогать** `BaseLayout.astro` (schema.org, GA4, Яндекс.Метрика, OG-теги — критично для SEO).
- **Не трогать** `scripts/` и логику генерации данных.
- **Не трогать** `src/data/cities-dataset.ts`, `src/data/jobs.ts`, `src/data/vacancies.ts` и алгоритмы.
- Сохранить мультиязычность (12 языков через `data-t` ключи).

## 3. Что менять — только это

### `src/styles/index.css` и `src/styles/themes.css`

- Обновить палитру `:root` (сейчас холодно-серая, primary `#1e293b`). Сделать чуть теплее, дружелюбнее, доверительнее. Цвета должны проходить WCAG AA (4.5:1 для текста).
- Перебрать переменные `--shadow-sm/md/glass`, `--radius-lg/xl`, `--transition` — единая шкала.
- Добавить шкалу spacing-токенов (`--space-1` … `--space-12`), если хочется опираться на CSS-переменные. Не обязательно, можно оставить hard-coded если это меньше изменений.
- Тёмная тема (`body.dark-mode`) — улучшить контраст и приглушённость, чтобы было приятно вечером. Без JS-флика на старте (`color-scheme: light dark` в `:root` + `prefers-color-scheme: dark` ветка).
- Тема `body.theme-original` — оставить как есть **или** удалить, если не используется (проверить `grep -rn "theme-original" src/`).
- Шрифт — можно оставить `system-ui`, можно подключить **один** веб-шрифт (Inter / Manrope / Geist) с `display: swap` и preconnect к `fonts.gstatic.com` в `BaseLayout.astro`. Если подключаешь — обязан обновить заголовки + body через `--font-main` / `--font-heading`, не вручную в каждом компоненте.
- Удалять можно только заведомо мёртвые правила (после `grep` подтверждения).

### Компоненты `.astro`

Менять можно только содержимое `<style>` блоков и совсем мелкие правки разметки в пределах одного-двух классов (например, добавить обёртку для нового визуального эффекта). Полностью переписывать компоненты — нельзя.

Цели по компонентам:

- `Header.astro` — освежить логотип/навигацию, оставить текущий каркас. Иконки можно заменить на inline SVG (Lucide / Phosphor), без icon-font.

- `JobCard.astro` — улучшить иерархию: компания + локация → зарплата (выделена) → метаданные (транспорт, график) → CTA. Не менять данные, которые отображаются.
- `JobGrid.astro` — отступы, мобильные брейкпоинты, hover/focus карточек.
- `IncomeCalculator.astro` — числа крупнее, слайдер аккуратнее, кнопка заметнее.
- `ReviewsBlock.astro`, `ReviewModal.astro` — рейтинг визуально читаемее.
- `LanguageSwitcher.astro` — стилизовать dropdown, оставить текущую логику.
- `PartnerBanner.astro` — согласовать с новой палитрой и сделать вариант для dark-mode.
- `VPNModal.astro` — оверлей и контраст.

### Страницы

Внутри страниц (`index.astro`, `v/[slug].astro`, `[slug].astro`, `compare.astro`, `blog.astro`, `blog/[slug].astro`, `calculator.astro`, `cities.astro`, `companies/index.astro`, `companies/[slug].astro`, `contacts.astro`) можно менять **только** `<style>` блоки и косметические HTML-обёртки. Всю логику/данные/циклы оставить как есть.

Особое внимание:
- `pages/v/[slug].astro` — длинная страница, есть смысл добавить мягкие разделители между секциями, sticky-CTA на mobile (просто CSS, без JS).

- `pages/blog/[slug].astro` — типографика для длинных текстов (max-width 65–75ch, отступы между параграфами).

## 4. Эстетика и направление

Простой, спокойный, доверительный. Меньше «эффектов» — больше воздуха.

- Можно вдохновляться: HeadHunter (в плотности и привычности), Notion (в типографике и spacing), Linear (в состояниях и focus-кольцах), банковские мобильные приложения (Тинькофф, Альфа — в дружелюбной палитре).
- Не нужно: glassmorphism, neumorphism, сильный blur background, animated gradients, 3D-элементы, тяжёлые иконки.

Палитра — предложить 1 основной (брендовый, что-то отличное от чёрно-серого), 1 акцент-цвет (для CTA и важных тегов), плюс семантические success / warning / danger / info. Текст — серый с тёплым оттенком, не чисто холодный slate.

## 5. Доступность (обязательно)

- Контраст: 4.5:1 для основного текста, 3:1 для интерактивных элементов и крупного текста (≥18px).
- `:focus-visible` — заметное кольцо, не убирать `outline` без замены.
- `prefers-reduced-motion: reduce` — отключать transition'ы.
- `aria-*` атрибуты в существующей разметке не трогать.

## 6. Производительность

- Inline critical CSS уже включён (`build.inlineStylesheets: 'always'`). Не добавлять heavy stylesheets, которые блокируют рендер.
- Не подключать больше **одного** веб-шрифта.
- Не добавлять больших фоновых картинок без `loading="lazy"`.
- Lighthouse mobile после правок: Performance ≥ 90, A11y = 100, Best Practices ≥ 95, SEO = 100 (для главной и одной страницы вакансии). Если что-то деградирует — откатить.

## 7. Локальная среда

```bash
cd kurieros-astro
npm install
npm run dev          # http://localhost:4321/
npm run build        # production-сборка, ~60 секунд, ~6300 страниц
```

`predev`/`prebuild` запускают `generate:vacancy-translations` и `generate:reviews` — это нормально, не нужно трогать.
